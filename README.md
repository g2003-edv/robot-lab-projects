# 实验室机器人控制项目

> **技能关键词**：STM32 · PID 闭环控制 · ROS · 运动学逆解 · 步态规划 · 四足机器人 · 循迹避障 · 嵌入式开发 · C/C++ · Python

## 项目概述

在校实验室期间完成的两个机器人控制项目，覆盖**嵌入式底层控制**与**ROS 上层算法**两个层面：

| 项目 | 平台 | 核心技术 | 能力体现 |
|------|------|---------|---------|
| **循迹避障小车** | STM32F103 | PID 闭环、红外/超声波传感器融合、电机 PWM 调速 | 嵌入式控制、传感器集成、实时调试 |
| **四足步态控制** | ROS + Python | Trot 步态规划、运动学逆解、足端轨迹插值 | 机器人算法、运动学建模、软件架构 |

**与珞石机器人岗位匹配点**：
- 系统学习过**运动学、动力学建模**理论，并在四足项目中实践了**运动学逆解**
- 具备**机电系统调试**经验（电机驱动、I2C 传感器、串口通信）
- 熟悉 **C/C++** 嵌入式开发与 **Python** 算法实现双栈

## 1. STM32 循迹避障小车

### 硬件架构

```
┌─────────────────────────────────────┐
│           STM32F103C8T6             │
│  ┌─────────┐    ┌───────────────┐  │
│  │ 5路红外  │───→│   循迹逻辑     │  │
│  │ 传感器   │    │  (PID 计算)   │  │
│  └─────────┘    └───────┬───────┘  │
│  ┌─────────┐            │          │
│  │ HC-SR04 │───→──┐    │ PWM输出  │
│  │ 超声波   │      │    ↓          │
│  └─────────┘      └──→ 避障决策    │
│                         ↓          │
│                    ┌─────────────┐  │
│                    │ L298N 电机   │  │
│                    │ 差速驱动     │  │
│                    └─────────────┘  │
└─────────────────────────────────────┘
```

### 技术细节

| 维度 | 实现方案 |
|------|---------|
| **主控** | STM32F103C8T6 (ARM Cortex-M3, 72MHz) |
| **循迹** | 5 路红外传感器阵列，加权平均计算偏移量 |
| **避障** | HC-SR04 超声波测距，阈值 15cm 触发避障 |
| **电机控制** | L298N 双 H 桥，TIM2 PWM 调速，差速转向 |
| **控制算法** | PID 闭环（Kp=25, Ki=0.5, Kd=8），积分限幅 + 输出限幅 |
| **避障策略** | 检测到障碍物 → 停车 → 原地右转 90° → 继续循迹 |

### 核心代码结构

```
st32-line-tracking/
├── inc/
│   ├── pid.h          # PID 控制器结构体与接口
│   ├── motor.h        # 电机 PWM 控制接口
│   └── sensor.h       # 红外/超声波传感器接口
└── src/
    ├── main.c         # 主循环：读取传感器 → PID 计算 → 输出电机
    ├── pid.c          # PID 算法实现（位置式 + 抗积分饱和）
    ├── motor.c        # HAL 库 TIM PWM 输出封装
    └── sensor.c       # GPIO 读取 + 超声波时序（框架）
```

### 关键参数与成果

- **直线循迹误差**：控制在 **2cm 以内**
- **控制频率**：100Hz（10ms 周期）
- **PWM 分辨率**：1kHz，占空比 0–999
- **避障响应时间**：< 200ms（超声波测距 + 决策执行）

## 2. ROS 四足步态控制

### 软件架构

```
┌──────────────────────────────────────────┐
│           ROS Master (roscore)            │
│  ┌────────────────────────────────────┐  │
│  │    trot_gait_controller 节点       │  │
│  │  ┌─────────────┐  ┌─────────────┐ │  │
│  │  │ Trot 步态    │  │ 运动学逆解   │ │  │
│  │  │ 相位生成     │──→│ (IK)        │ │  │
│  │  └─────────────┘  └──────┬──────┘ │  │
│  │                          │        │  │
│  │  ┌───────────────────────┘        │  │
│  │  ↓                                 │  │
│  │  /joint_states (sensor_msgs)       │  │
│  └────────────────────────────────────┘  │
└──────────────────────────────────────────┘
```

### 技术细节

| 维度 | 实现方案 |
|------|---------|
| **平台** | ROS Noetic / Melodic |
| **语言** | Python 3 + NumPy |
| **运动学** | 3-DOF 单腿，解析法逆解（IK），连杆参数 L1=45mm, L2=L3=100mm |
| **步态** | Trot（对角腿同步），占空比 0.5 |
| **轨迹** | 摆相 Cycloid 曲线（足端抬升 3cm，步长 6cm） |
| **发布频率** | 50Hz（周期 20ms） |

### 核心代码结构

```
quadruped-ros/
└── src/quadruped_gait/
    ├── scripts/
    │   ├── kinematics.py      # 运动学正解 + 逆解（解析法）
    │   └── gait_controller.py # Trot 步态生成节点
    ├── launch/
    │   └── trot_gait.launch   # 启动文件
    ├── CMakeLists.txt
    └── package.xml
```

### 运动学逆解公式

单腿 3-DOF 解析逆解：

```
θ₁ = atan2(y, x)                                    # 髋关节偏航角
r  = √(x² + y²) - L₁                                # 投影到腿平面
d  = √(r² + z²)                                     # 腿平面距离
θ₃ = -arccos( (L₂² + L₃² - d²) / (2·L₂·L₃) )      # 膝关节
θ₂ = atan2(z, r) + arccos( (L₂² + d² - L₃²) / (2·L₂·d) )  # 髋关节俯仰角
```

### 步态时序

```
Time →  0.0s    0.2s    0.4s    0.6s    0.8s
        ├───────┼───────┼───────┼───────┤
FL/RR   │  STANCE        │  SWING         │  (周期 0.8s)
FR/RL   │  SWING         │  STANCE        │
        └───────┴───────┴───────┴───────┘
        STANCE = 支撑相（占空比 50%）
        SWING  = 摆相（足端离地前移）
```

## 快速开始

### STM32 小车（Keil / STM32CubeIDE）

```bash
cd stm32-line-tracking/
# 使用 Keil 打开项目，或 STM32CubeIDE 导入
# 连接 ST-Link，编译下载
```

### ROS 四足（Ubuntu 20.04 + ROS Noetic）

```bash
cd quadruped-ros/
catkin_make
source devel/setup.bash
roslaunch quadruped_gait trot_gait.launch
```
